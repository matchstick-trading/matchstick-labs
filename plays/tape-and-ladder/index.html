TAPE & LADDER

Everything below is a number. If you can see it, you can stand on it — the price tape as terrain to run and jump, the order book as a wall of ledges to climb. No charts, no 3D, just glyphs mapped from data, same trick as the ASCII heightmap game this borrows from.

STANDING ON —
An early sketch exploring one question: what's the smallest interaction that proves a spatial way of browsing market data? Left panel maps max(open,close) per bar to a walkable ledge, the wick above it to a thin non-solid spike. Right panel maps order size to ledge width; climbing crosses the spread. Synthetic data, regenerates each run — not wired to any real session or trading system.
