matchstick-labs

Playful R&D and control-scheme experiments. Not the Matchstick Replay product.

  • Tape & Ladder
    Run the tape, climb the ladder, don't get stopped out.
  • Find the Moment
    Describe an episode. Jev ranks which windows match. You reveal the truth.
  • Backtest Autopsy
    Code finds the facts. Jev triages which of 45 backtests to check next.
  • Market Data Incident Lab
    Frozen quotes, crossed books, bad splits — and a genuine news move as a trap.
  • Decision Boundary Lab
    No corpus, no symbol. Move one feature and watch Jev's distribution shift.
  • Agent Intent Firewall
    Paper-trade drafts only. LLM drafts, code computes risk, Jev judges, code decides.

Systems behind the plays

  • Jev Regime Screener
    Standalone System One experiment — its API also powers Find the Moment, Backtest Autopsy, and Market Data Incident Lab.
  • OpenCandle
    The open candle and metadata format used by the research.
